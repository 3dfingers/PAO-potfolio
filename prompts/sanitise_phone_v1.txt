CONTEXT:

- If the digits start with 0, replace the 0 with 44.

- Do NOT add a second 44 to a number that already starts with 44 or +44 (must never produce "+44447700900123").
- Do NOT accept non-UK numbers (e.g. "+1 555 123 4567" must raise ValueError).
- Do NOT use a bare except.
- Do NOT use any external libraries.

OUTPUT FORMAT:
Return only the Python function, with this exact signature:
def sanitise_phone(raw: str) -> str:
It must return the cleaned number as a string in the format "+447700900123".
Include a short docstring and type hints.
